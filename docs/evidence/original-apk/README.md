## 5. 罗盘模式结构（orig-06，决定性证据）

点左列「罗盘」后**不换页**，仍在同一页面，罗盘以半透明浮层叠加在地图中心：

- 罗盘圆盘**浮在地图中心**（圆心约在屏幕几何中心），24 山环 + 外圈 1–360° 度环 + 红色十字准线 + 红色指北箭头
- 顶部栏变为：返回箭头、`搜索`、`图层`、`隐藏`（隐藏罗盘回到地图态）
- 右侧开关：`地图`（开）、`实景`（关）、`坐南朝北`（关）、`指针开关`（开）
- 左列工具切换为：`截屏`、`等高线`、`罗盘复位`、`罗盘锁定`、`读盘`、`贴地`
- 底部工具条（非导航）：`切换`、`旋转`、`缩放`、`透明度`、`天支线`
- 左上读数：`坐180° 向0°`；地图比例尺与坐标保留

即：**地图与罗盘是同一个页面的两种表现**；底部「切换/旋转/缩放/透明度/天支线」是罗盘操作工具，不是页面导航。

## 7. 对 LC 的改造结论（K-01 定案）

1. **删除底部三 Tab（罗盘 / 地图 / 知识）**。原版没有底部导航；三 Tab 是复刻过程中为了给独立罗盘页与知识页找落点而新增的，与原件不符。
2. **主界面改为单页全屏地图**，左列/右列工具按 §4 的按钮与位置还原；`罗盘` 是左列一个按钮。
3. **罗盘改为浮层**：点击「罗盘」在同一页面把罗盘圆盘叠加到地图中心（圆心≈屏幕中心），保留地图半透明可见；顶部栏、右侧开关、左列工具、底部罗盘工具条按 §5 切换。
4. **读数面板（读盘）用弹层/面板呈现**，不占独立页面；知识条目同样以底部面板或抽屉承载（对照 §6 的 bottom sheet 逻辑），不做 Tab。
5. **底图来源差异必须如实标注**：原版底图是「世纪空间」影像（审图号 `GS(2026)1219号`）；LC 目前用天地图，属**等价替代**，**不得**照抄该审图号（审图号与底图服务商绑定）。这一点同时更新 PRD 的 T-13 与审查报告的相关待确认项。

## 8. 证据限制（必须如实声明）

- 罗盘浮层为自绘（Canvas/Compose 自定义绘制），`uiautomator dump` 只能拿到 1 个原生节点，**无法**得到浮层内部控件层级；浮层几何只能由截图测量。
- 引导气泡（首次进入罗盘模式的「点击左侧工具…」）只在首次出现，截图 `orig-05` 已保留。
- 未采集：登录/会员流程（不复刻）、天气/钓点等工具子页（未做，不属 K-01 范围）。
