## 3 与原版的关系

### 3.1 1:1 / 等价复刻范围

- **罗盘**：24 山、地盘/人盘/天盘三盘、百二十分金、穿山七十二龙、透地六十龙、64 卦、先后天八卦、五行、正兼向、14 类读数（原版 VIP 墙已解除；读数公式与 `mechanics.json` 同源）。

- **底图交互**：矢量/影像/地形、注记、3D 俯仰/旋转/缩放、定位、立向标记、截图。
- **工具入口**：18 项入口位置与文案按原版坐标/文案还原（文案见各 `F-xx` 文档）。
- **桌面版**：演示与自动验收载体，读数与数值必须与 Android 一致（D-003）。

### 3.3 结论口径（写死）

> **本项目 18 项是按「自用、免费、无门槛」重建的 18 个能力入口，不是原版付费能力的等同物。** 原版靠会员/云端服务/第三方付费数据集支撑的部分，LC 用免费替代、本机实现或明确占位处理。收官报告**不得**表述为「已完整复刻全部付费功能」；复刻的是功能入口与可做部分，付费能力本身不在复刻范围。

### 4.1 密钥管理

- **存放**：天地图个人 key（用户自备）存**仓库外** `E:\APPDetector\secrets\tdt.properties`，构建期注入 `BuildConfig.TDT_SERVER_KEY` / `TDT_WEB_KEY`，**全仓零字面量**。
- **两把 key 不能混用**：服务端 key 配原生 UA 用于 Java 侧逆地理/检索；网页端 key 配浏览器 UA 用于 WebView 瓦片。混用返回 `301013 权限类型错误`（实测结论）。
- **闸门**：`tests/secrets/secret_gate.py` 扫全仓，真 key 命中即 FAIL（已接入 smoke）；旧第三方 key `dd1885…` 已失效（`301001 非法key`），代码里不再出现。
- **轮换**：只改 `secrets/tdt.properties`，构建自动生效；仓库是 **PUBLIC**，**禁止任何 key 入库**（含文档、测试夹具、截图、日志）。
- **冻结报告的旧 key 字面量**：`docs/review/20-M3-map.md`、`50-M6-docs.md` 含旧 key（`dd1885…`）完整字面量，属**冻结基线证据**（sha 前缀 `75108000C87DFD84`），按纪律**不修改**；该 key 已 `301001` 失效，风险为零。
