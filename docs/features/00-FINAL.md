## 3 与原版的关系

### 3.1 1:1 / 等价复刻范围

- **罗盘**：24 山、地盘/人盘/天盘三盘、百二十分金、穿山七十二龙、透地六十龙、64 卦、先后天八卦、五行、正兼向、14 类读数（原版 VIP 墙已解除；读数公式与 `mechanics.json` 同源）。
- **主界面结构（K-01）**：单页全屏地图 + 左列 8 工具 + 右列 10 工具 +「更多」16 格 + 罗盘同页浮层（不做底部导航）。
- **底图交互**：矢量/影像/地形、注记、3D 俯仰/旋转/缩放、定位、立向标记、截图。
- **工具入口**：18 项入口位置与文案按原版坐标/文案还原（文案见各 `F-xx` 文档）。
- **桌面版**：演示与自动验收载体，读数与数值必须与 Android 一致（D-003）。

### 3.2 明确不做 / 不等同（本条决定收官报告能不写什么）

### 3.3 结论口径（写死）

> **本项目 18 项是按「自用、免费、无门槛」重建的 18 个能力入口，不是原版付费能力的等同物。** 原版靠会员/云端服务/第三方付费数据集支撑的部分，LC 用免费替代、本机实现或明确占位处理。收官报告**不得**表述为「已完整复刻全部付费功能」；复刻的是功能入口与可做部分，付费能力本身不在复刻范围。

## 4 数据来源与合规

| 用途 | 来源 | 事实/许可 | 约束 |
|---|---|---|---|
| 底图/注记/搜索/逆地理 | 天地图（个人 key） | 官方在线服务；服务端 WAF 拒非浏览器 UA（403/418，客户端统一 UA） | 不自建瓦片、不对外提供瓦片；key 不外发 |
| 3D 高程 | AWS Terrarium DEM | 公开数据集（open data） | 可本机缓存；境外源，失败回落 2D |
| 历史影像 | Esri Wayback | 需标注来源与许可 | 不复制原版 Google 历年影像 |
| 探索/专题图 | Wikimedia Commons（CC） | 逐图署名 + 许可 | 不搬会员专题数据 |
| 地理影像 | Bing 每日壁纸（公开图库） | 摄影师署名 + 来源标注 | 自用，不商用 |
| 基础地理参考 | OSM（如用到） | ODbL 署名 | 遵守署名 |
| 轨迹数据 | 用户自采 GPS | 用户自己的数据 | 仅本机存储，不上传 |

**合规红线三条（验收会直接判）**

1. **零付费数据提取**：不搬第三方会员数据集、不调用付费接口、不做假数据。
2. **零审图号照抄**：LC 用天地图，天地图审图号未确认前标「待确认/待核对」；**禁止沿用**世纪空间 `GS(2026)1219号`，也禁止套用高德/腾讯的号。
3. **零第三方付费文案**：页面/all toast/空态不得出现「会员 / VIP / 开通 / 升级 / 试用 / 解锁 / 付费 / 订阅 / 去水印」。

其他：风水内容仅本地使用、不传播；不接第三方付费/广告 SDK；不上传位置与记录。
