## 2 界面结构（由字符串与方法名还原，截图待补）

`SuperMapListActivity`（36 方法）三段式：

1. **空/引导**：`OutLineButton`（`SuperMapListActivity.kt:279`）→ 发起「生成超清地图」；
2. **成功态** `SucLayout`（kt:257）：每条记录卡片 → `预览` / `导入地图` / `取消导入` / `删除`；

`SuperMapPreviewActivity`（42 方法）：瓦片预览 + 下载（失败文案 `下载图片失败，响应码: `），模型 `SuperMapRecordModel` / `Tile`。

## 6 LC 复现方案

- **开放实现**：不做 VIP 门；左列「超清优化」与「更多→超清地图」都直开。
- 落点：新建 `lc_supermap` 页，结构照抄三段式（列表/进度/失败重试），但生成能力改成**本地能力**：
  - 方案 A（推荐）：**高分辨率拼接导出**——用户框选区域 + 选层级（z14–z18），后台按天地图影像瓦片拼接为 PNG/JPG 存相册；
  - 方案 B（可选增强）：本地超分（Real-ESRGAN/MobileSR ONNX）对拼接图放大 2×，标注「本地增强」；
  - 不做服务端任务队列（无算力也不必要）。
- 开关：`lc_feature_supermap`。

## 6.1 无门槛实现方案

- 无 VIP/登录/内购；不设「限时体验」「每日次数」「导出需会员」。
- 「超清地图」角标去掉；两入口行为一致（都开本地拼接页）。
- 生成结果直接存本地相册，可分享。
