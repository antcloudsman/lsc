## 6 LC 复现方案（落点/接口/开关）

- 落点：`MainActivity` 左列「海拔查询」按钮 → 进入 LC 的「海拔模式」：地图右上角切地形/等高线，底部弹信息卡。
- 接口：
  - 高程：`map.html` 暴露 `lc_queryElevation(lng, lat)`；前端调到天地图/Mapbox 地形瓦片或 DEM 采样。
  - 逆地理：`lc_reverseGeocode(lng, lat)`。
  - 含氧量/气压：前端按高程算（公式见 §6.2）。
- 开关：`lc_feature_altitude`（默认开）。

## 6.1 无门槛实现方案

- 无会员/登录/内购判断；任何用户点「海拔查询」直接进入。
- 不做次数限制、不做「VIP 才能看气压/含氧量」的门；四项数值全开放。
- 「打点」保存到本地收藏（与 F-11 共用）。

## 6.2 免费数据替代

| 能力 | 替代方案 | 说明 |
|---|---|---|
| 高程 | 天地图地形服务 / Mapbox Terrain-RGB（免费额度）/ Open-Elevation（SRTM）| 天地图个人 key 可申请；SRTM 30m 全球免费 |
| 逆地理 | 天地图逆地理 API / Nominatim（OSM，免费） | Nominatim 需限速 |
| 含氧量 | 自算：`O2% ≈ 20.9 * exp(-h/44330 * ... )` 或常用 `20.9 - 0.0004*h` 近似 | LC 统一用一条公式并在 UI 标注「估算」 |
| 气压 | 自算：`p = 1013.25 * (1 - 2.25577e-5*h)^5.25588` | 与高程同源 |
| 地址 | 同逆地理 | — |

## 7 验收判据（可测）

1. 点「海拔查询」进入海拔模式，底部卡出现，无 VIP/登录拦截。
2. 中心点移动后经纬度与地址更新；高程数值在 ±1s 内回填。
3. 含氧量/气压随高程变化，且 UI 标注「估算值」。
4. 「打点」后该点进入收藏列表。
5. 返回键退出海拔模式回主页。
