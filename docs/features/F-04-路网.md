# F-04 路网

## 1 入口与页面

| 项 | 值 |
|---|---|
| 入口 | 主页左列第 6 个「路网」（交叉道路图标） |
| 坐标 | (124, 1837)（1228×2700） |
| 承载 | 地图图层开关（无独立页面） |
| 触发 | `MainActivity.V8` case17 → `MainViewModel.I3()` |

## 2 界面结构

- 按钮常态：深灰底 + 白色「路网」图标文字。
- 开启态：**整块变主题蓝**（截图 `_state.png` 中路网按钮为蓝色高亮），地图叠加路网注记。
- 无面板、无弹窗、无二次确认。

## 3 业务逻辑（逐指令）

`MainViewModel.I3()`（code_units=22）：

| 偏移 | 指令 | 含义 |
|---|---|---|
| 0x0000 | `invoke-virtual p1()Z` → `move-result v0` | 取当前 `showRoad` 状态 |
| 0x0004 | `xor-int/lit8 v0, v0, 1` | 取反 |
| 0x0006 | `invoke-virtual B2(Z)` | 写 UI 状态（按钮高亮） |
| 0x0009-0x000f | `MapManager.setShowRoad(Z)` | 落盘 + 通知地图 |

配套：`MapManager` MMKV 键 `showRoad`，缺省 **true**；setter 发 `event_show_road_changed`（见 `../../gap-modules/MapSettingActivity.md` §4 与 `app/MECHANICS.md` R5.2）。

## 4 数据来源与授权

- 路网注记来自**底图源本身**（真机角注 `数据来自世纪空间 审图号: GS(2026)1219号`），不是独立接口。
- 授权：世纪空间商业图源，**无授权**。

## 6 LC 复现方案

- 落点：`MainActivity` 左列按钮 → 调 `map.html` 的图层开关 `lc_setRoad(boolean)`。
- 数据：天地图矢量底图自带路网注记（`vec_w`/`cva_w`）；若用影像底图，则叠加天地图注记层 `cia_w`。
- 开关：即按钮本身；状态持久化到 LC 的设置（键名对齐 `showRoad`）。
- 与 F-05「叠加」共用图层管理：路网属于叠加层之一，状态互不干扰。

## 6.1 无门槛实现方案

- 无任何会员/登录判断，按钮直接切层。
- 默认开启（与原版一致 `showRoad=true`）。

## 7 验收判据（可测）

1. 点「路网」按钮，按钮变蓝且地图出现/消失路网注记。
2. 重启 App 后状态保持（默认开）。
3. 与「图层」「叠加」切换互不打架；3D 模式下仍生效。

- 工作量：**0.5 人日**（LC 侧已有图层开关能力，主要是接按钮 + 持久化 + 高亮态）。
