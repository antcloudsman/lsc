# F-05 叠加（叠加设置）

## 1 入口与页面

| 项 | 值 |
|---|---|
| 入口 | 主页**右列第 2 个**「叠加」（叠层图标） |
| 坐标 | ≈(1097, 700)（1228×2700；右列自上而下：图层 ≈493、叠加 ≈700、山脉 ≈902、水系 ≈1108、探索 ≈1312） |

## 2 界面结构

- 按钮：深灰底 + 图标 `R.drawable.svg_overlay` + 文字「叠加」（`F6` 侧栏 @0x01a3-0x01d0，`compose.a2.e(iconRes, "叠加", …, onClick=D3)`）。
- 点击后由 `MainViewModel.L2(true)` 把字段 `E:Landroidx/compose/runtime/MutableState<Boolean>` 置 true，驱动叠加设置浮层显示。
- **浮层面板本窗口未捕获**（设备被华为应用市场/安装器抢占，重试三次未拿到；见 §5）。面板内容待补，但入口、状态位与调用链已闭合。

## 6 LC 复现方案

- 落点：右列「叠加」按钮 → 打开 LC 的**图层浮层**（bottom sheet），列出可叠加项与开关：
  - 路网（F-04，天地图注记 `cia_w`）
  - 等高线（LC 已有，DEM 生成）
  - 水系（F-07，公开水系矢量）
  - 行政区边界（LC 已有 `admin_boundary_list` 等价）
  - 影像/地形切换（F-02 相关）
- 接口：`map.html` 暴露 `lc_setOverlay(id, on)`、`lc_getOverlays()`。
- 开关：`lc_feature_overlay`（默认开）。

## 6.1 无门槛实现方案

- 不做 VIP 前置；点「叠加」直接出浮层。
- 所有叠加项默认对全部用户开放，逐项独立开关，状态本地持久化。
- 不显示「会员专享」角标。

## 6.2 免费数据替代

| 叠加项 | 免费源 |
|---|---|
| 路网 | 天地图矢量/注记（`vec_w`/`cva_w`/`cia_w`） |
| 等高线 | 自建：DEM（SRTM/Copernicus）等值线，或天地图地形 |
| 水系 | OSM `waterway`/`natural=water` 矢量（Geofabrik 免费下载） |
| 行政区 | 天地图行政区服务 / 民政部公开边界 |
| 影像 | 天地图影像（个人 key） |

## 7 验收判据（可测）

1. 点「叠加」直接出现图层浮层，无 VIP/登录页。
2. 浮层内每项可独立开关，立即生效，关闭浮层后状态保持。
3. 与「图层」「路网」按钮状态一致（同一状态源）。
4. 重启 App 后叠加状态保持。
