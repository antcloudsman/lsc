## 4 数据来源与授权

`assets/webapp/js/gmba.*.bundle.js` 内命中的图层地址：

| 图层 | URL |
|---|---|
| GMBA 300 | `https://mapoverlay.xinzhi.space/overlay/gmba_300/{z}/{x}/{y}.pbf` |
| GMBA basic | `https://mapoverlay.xinzhi.space/overlay/gmba_basic/{z}/{x}/{y}.pbf` |
| 山地地形底图 | `https://mapoverlay.xinzhi.space/3dterrain/nasa/tiles/{z}/{x}/{y}.png` |
| 等高线 | `https://contour.a.lysian.top/{z}/{x}/{y}`、`contour.b...` |

`GMBA` = Global Mountain Biodiversity Assessment（全球山地生物多样性评估）数据集；**瓦片由原版 CDN `mapoverlay.xinzhi.space` 托管**。

授权判定：底层数据来源为公开科研数据集，但**原版瓦片服务是私有托管，不可直接引用**（带宽/授权/稳定性都不可控）。

## 6 LC 复现方案

- **开放实现**：右列「山脉」与「更多→看山脉」直开，无 VIP 门。
- 落点：LC 新页 `lc_mountain`（原生地图 + 图层），复用 `map.html` 的 3D 地形与矢量图层能力。

## 9 查询链路诊断（2026-11-05）：空结果根因 = UA 被天地图 WAF 拒（403）

**症状**：真机 `MountainActivity --ef lc_lat 36.25 --ef lc_lng 117.10`（泰山）返回「该区域没有检索到山名点」，北京正常。

**原始报文（PC 复现）**：

1. 逆地理 `200`：泰山 → `province_code=156370000`（山东省，status 0），省码本身没错。
2. 省码 + 分类 `200`：`queryType=13&dataTypes=260203&specify=156370000` → `infocode=1000`、`resultType=1`、`count=117`、首条「虞山」；北京对照 `count=202`。无 `T00x` 配额/权限错误。
3. **UA 矩阵（同 URL 同参数，只换 User-Agent）**：

| User-Agent | 结果 |
|---|---|
| 不带 UA（PowerShell 默认） | **200**，count=117 |
| `Mozilla/5.0 (…) Chrome/120 … Safari/537.36` | **200**，count=117 |
| `Luopan/1.0 (Android)`（原 `LcHttp` 写死） | **403 Forbidden** |
| `okhttp/4.12` / `Dalvik/2.1.0 …` | **403 Forbidden** |

**结论**：不是省码、不是参数、不是配额；`LcHttp` 写死非浏览器 UA，天地图 WAF 一律 403，导致
「省码为 null → 分类搜索空 → 视野兜底也空 → 页面显示没数据」。

**修复**：UA 集中到 `LcHttp.UA`（浏览器形态，`SuperMapActivity` 瓦片/Bing/天气共用）；查询保持
「省码分类先、空则视野搜索兜底」，状态栏显示「（省检索为空，已改用视野搜索）」，不把兜底显示成无数据。

**复核命令**：

```powershell
$k='<天地图 key>'
$q=[System.Uri]::EscapeDataString('{"queryType":13,"start":0,"count":5,"specify":"156370000","dataTypes":"260203"}')
# 403（旧实现）
Invoke-WebRequest "https://api.tianditu.gov.cn/v2/search?postStr=$q&type=query&tk=$k" -Headers @{'User-Agent'='Luopan/1.0 (Android)'}
# 200 / count=117（现实现）
Invoke-WebRequest "https://api.tianditu.gov.cn/v2/search?postStr=$q&type=query&tk=$k" -Headers @{'User-Agent'='Mozilla/5.0 (Linux; Android 12; LC) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0 Mobile Safari/537.36'}
```
