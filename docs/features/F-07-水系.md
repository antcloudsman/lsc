## 6 LC 复现方案

- **开放实现**：右列「水系」与「更多→看水系」直开，无 VIP 门。
- 落点：`lc_water` 页（原生地图 + 水系图层），复用 `map.html`。
- 图层：`lc_setWaterLayer(on)`；分级渲染（一级河/二级支流/湖泊/水库/瀑布）。
- 点击对象弹信息条（名称/类型/长度/所属流域），数据来自自建瓦片属性。

## 6.1 无门槛实现方案

- 无会员/登录；不设「会员查看全球水系」的限制。
- 全球与中国水系全开放；搜索不限次数。

## 6.2 免费数据替代

| 原版 | 替代 |
|---|---|
| china_water_l/p（私有 pbf） | **OSM 水系**（`natural=water`、`waterway=river/canal/stream`）自建 vector tiles（Geofabrik 中国 extract，ODbL） |
| 全球水系 | OSM 全球 extract（按需裁剪）或 HydroSHEDS（公开水文数据） |
| 瀑布/湖泊分级 | OSM `waterway=waterfall`、`natural=water` + `water=lake/reservoir` |
| 底图 | 天地图矢量/地形 |

> 生成链路：Geofabrik → osmium 过滤水系 → tippecanoe 出 pbf → 本地静态托管；体积可控（中国水系约数 GB 原始，过滤后几百 MB）。

## 9 查询链路诊断（2026-11-05）：空结果根因 = UA 被天地图 WAF 拒（403）

**症状**：真机 `WaterActivity --ef lc_lat 29.35 --ef lc_lng 112.95`（洞庭湖）返回「没有检索到河湖点」，北京正常。

**原始报文（PC 复现）**：

1. 逆地理 `200`：洞庭湖 → `province_code=156430000`（湖南省，status 0）。
2. 省码 + 分类 `200`：湖南 `260205` → `count=36`、`260204` → `count=28012`（`infocode=1000`、`resultType=1`）；无 `T00x` 配额错误。
   （已知限制：`dataTypes` 用逗号传多值会返回空，所以河流/湖泊分两次查。）
3. **UA 矩阵（同 URL 同参数，只换 User-Agent）**：

| User-Agent | 结果 |
|---|---|
| 不带 UA（PowerShell 默认） | **200** |
| `Mozilla/5.0 (…) Chrome/120 … Safari/537.36` | **200** |
| `Luopan/1.0 (Android)`（原 `LcHttp` 写死） | **403 Forbidden** |
| `okhttp/4.12` / `Dalvik/2.1.0 …` | **403 Forbidden** |

**结论**：与 F-06 同源——UA 被天地图 WAF 拒，逆地理/分类/视野搜索全部 403，页面才显示「没有数据」。
**修复**：UA 集中 `LcHttp.UA`（浏览器形态）；查询保持「省码先、空则视野兜底」，状态栏标注
「（省检索为空，已改用视野搜索）」。

**复核命令**：

```powershell
$k='<天地图 key>'
$q=[System.Uri]::EscapeDataString('{"queryType":13,"start":0,"count":5,"specify":"156430000","dataTypes":"260205"}')
Invoke-WebRequest "https://api.tianditu.gov.cn/v2/search?postStr=$q&type=query&tk=$k" -Headers @{'User-Agent'='Mozilla/5.0 (Linux; Android 12; LC) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0 Mobile Safari/537.36'}
```
