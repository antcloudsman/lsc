**打点方式（重要，客户端别做错）**：JS 侧 `drawTool.addCenterPoint()` 的实现是

```js
addCenterPoint(){ let e=this.map.getCenter(), t=this.map.project(e); this.eventClick({point:t,lngLat:e}) }
```

即**「添加点」= 取当前屏幕中心的地理点并当作一次点击**——用户的操作模型是「拖动地图把准星对到目标 → 点添加点」，不是「点哪打哪」。

**吸附：没有。** 全 bundle 搜 `snap` / `吸附` 均 0 命中，DEX 侧也无吸附相关常量——LC 不要自作主张做 POI 吸附。

> 未确认：除「添加点」外，地图直接点击是否也加点（测距/测面模式内部实现已压缩，未定位到对应分支）。客户端按「中心点打点」实现即可覆盖原版主路径。

## 6 LC 复现方案

- 落点：`map.html` 增加 `lc_measure_start(mode)` / `lc_measure_clear()`；`mode ∈ {distance, area}`。
- UI：照原版的**两个命名模式**「测距与方位角」「测面积与周长」+ 动作 `添加点 / 撤销 / 完成 / 返回`，再加同款开关行（设置/指北针/等高线/定位/3D/地形对比）。
- 打点：**屏幕中心打点**（`addCenterPoint` 语义），配合中心准星；**不做吸附**（原版没有）。
- 读数：距离模式要同时给「坐 / 向」方位角（原版初值 `坐180° 向0°`）；面积模式给周长+面积。
- 单位：距离 SI/EU/NMI，面积 SI/MU/HA 两组（`EU` 待定名）。
- 计算：WGS84 椭球 Haversine（距离），面积用球面多边形或投影平面。
- 开关：`lc_feature_measure`。
