## 3 业务逻辑

| 偏移 | 指令 | 含义 |
|---|---|---|
| `MainViewModel.E1()` @0x0000 | `new ui.controller.i(mapWeb)` | 创建画笔控制器 |
| @0x0007 | `j2(controller)` | 挂载 |
| @0x000e | `const-string "paint_brush_show"` | 埋点 |

JS 桥（`map/MapWebApiKt`，画笔侧实际调用）：

| 桥方法 | 参数 | 用途 |
|---|---|---|
| `drawSetStyle` | `(String color, int width)` | 下发颜色 + 粗细（`i.e()` 取宽度、`i.i()` 取颜色） |
| `drawMeasureHand` | `(String color, int width)` | **画笔手势模式**（参数同样是色+宽度） |
| `drawMeasureMapMode` | `("map")` | **地图模式**（切到可拖动/缩放，不绘制） |
| `drawUndo` / `drawDelete` / `drawFinish` | — | 撤销 / 删除 / 完成 |

> 桥名带 `measure` 是历史命名：`drawMeasureHand` / `drawMeasureMapMode` 是绘制工具**通用**的手势/地图模式开关，测量与画笔共用（测量侧也调同一组）。

**橡皮：没有。** 全 bundle 搜 `eraser`/`橡皮` 0 命中，DEX 里也没有橡皮相关常量或状态；原版只有 `撤销 / 删除 / 完成` 三个动作。JS 侧虽然暴露了 `drawClear`，但 Java 侧**从未调用**——客户端不要实现「橡皮擦」，也不要自动补一个「清空」按钮当成原版。

> 未确认：`色板 5 色 + 粗细 3 档` 之外，`[12,14,16]` 那组值在 UI 上的具体行标签（`粗细` 行只出现过一次）。若客户端要 1:1，先只做 5 色 + 2/4/6。

## 6 LC 复现方案

- 落点：`map.html` 增加 `lc_draw_start()` / `lc_draw_clear()` / `lc_draw_undo()` / `lc_draw_export()`。
- 交互：单指绘制、双指缩放；**5 色**（#2E75FE/#FF0000/#36B44B/#F9C30F/#000000，默认红）+ **3 档粗细**（2/4/6，默认 4）；`撤销/删除/完成`；模式 `画笔/地图`；**无橡皮**。
- 颜色与粗细要 **MMKV 记忆**（键名 `selectedColor` / `selectedStrokeIndex`，与 F-13 §2 一致），下次进入沿用。
- 导出为图片（复用截屏链路）。
- 与 F-11 联动：绘制结果可存为「标注图层」（不进收藏点列表）。
