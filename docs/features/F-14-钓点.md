- 由 `ui.controller.j`（钓点专用控制器）管理筛选/详情面板。
- **真机实测的图层形态（窗口 3）**：
  - 点位不是小图钉，而是**带字的圆形水滴标记 + 地名文字**；标记内一个字区分类型：`库`（水库）、`河`、`塘`、`黑`（黑坑/收费塘），并且**按类型分色**（库=橙、河=蓝、塘=紫、黑=深灰）。
  - 标记下直接渲染名称，实测样本：`祝峰鱼塘休闲垂钓园`、`水涨钓场`、`月亮湾渔庄`、`棉花塘靖江鱼场`、`小东塘养殖场`、`马栏基渔场`、`清江村鱼塘`、`合作塘河`、`龙避岙`、`河塘钓鱼…`。
  - 点位密度很高（一屏 30+），且与天然水体混排（`森林公园水库`、`福溪水库`、`本觉寺水库`、`江沿水库`、`长潭日溪村溪流`、`河沿村野河`、`庄前村山塘`）——说明底层是**全国水域/钓场底库**，不是用户 UGC。
  - 左下角：比例尺 `4km` + 实时坐标 `121.075103，28.364344`（App 默认视野在浙江台州/乐清一带）；底部注记 `数据来自世纪空间 审图号：GS(2026)1219号`。

### 3.2 有没有「筛选面板」（已闭合：没有）

- 全 DEX 里 `ui.controller.j` 只有 4 个状态（详情/文案/导航/天气）+ 类型文案映射，**没有任何筛选条件、筛选列表或过滤请求**；
- 全工程搜「库钓/河钓/塘钓/黑坑」，除 `j.d(I)` 这个**展示用**映射外，没有第二处使用（`strings.xml` 里也没有这几个词，说明是代码内硬编码标签，不是资源）；
- `MapWebApiKt`/`map.html` 侧没有任何按类型过滤的接口；WebView bundle 里也**没有** `库钓/黑坑` 字样。
- 结论：**原版钓点 = 一个总图层开关 + 点开单点详情，不做筛选、不做列表页。** LC 若要加筛选，属于增量功能，文档 §6 已按「自建」写，不冒充 1:1。

### 3.3 关图层再开：状态是否记忆（已闭合：不记忆）

- `"fishSport"` 在全 DEX 仅 2 处：`MainViewModel.F1` @#@12–16（开，`true`）与 `MainViewModel.O()` @#@6–9（关，`false`）。
- `O()` 的实现是 `k2(null)` 清掉控制器 + `setOverlayVisibleByCode(mapWeb,"fishSport",false)`；`O()` 只有两个调用点：`Z1.smali:38`（UI 的关闭动作）与 `MainViewModel.smali:11632`（「关闭当前工具」分发链里，`b0() != null` 即当前工具是钓点时）。
- `setOverlayVisibleByCode` 本体（`map/MapWebApiKt.smali` @4854）只做两件事：把 `AppConfig.getLastOverlayLineOpacity()/getLastOverlayFillOpacity()`（÷100）下发 `setOverlayOpacity`，再把 `{code: visible}` 塞进一个 `JsonObject` 下发 WebView。**没有任何存储/读回**。
- 结论：**开关状态不落盘、不记忆**——离开钓点工具（或进程重建）即恢复关闭，下次必须重新点「钓点」。LC 若要做「记住上次开启」，属增量，需在文档里标注非原版。

## 6 LC 复现方案

- **开放实现**：不做 VIP 门，也不做「首次引导弹 VIP」；点「钓点」直接打开图层 + 面板。
- 落点：`map.html` 增加 `lc_setFishLayer(on)`，数据两层：
  1. **公开水域**（OSM 水体/河道）自动渲染为「可垂钓水域」候选；
  2. **用户自建钓点**（UGC）：地图长按或「+」新增，字段 `name/鱼种/水深/费用/备注/坐标/照片`，存本地 + 可选同步到自建后端。
- 面板：单点详情卡（标题+类型徽标+地址+距我+收费方式+图片+实时天气+收藏地点/导航/关闭）；**筛选/列表为 LC 增量**（原版无，见 §3.2，UI 上需标注非原版）。
- 开关：`lc_feature_fish`。原版**不记忆**开关态（§3.3）；LC 若要记忆，需在文档/UI 标注增量。

**1:1 必须保留的行为**（客户端抄这几条即可）：

1. 点「钓点」= 直接开图层，无二级页、无 VIP 引导；
2. 点标记 → 先出详情（异步两次请求：详情 + 该点实时天气），详情卡含「距我:」距离；
3. 类型 4 种（303 库钓 / 308 河钓 / 309 黑坑 / 其它塘钓），徽标与标记颜色随之变化；
4. 卡上只有 3 个动作：收藏地点（进新增收藏页预填）/ 导航（GCJ02）/ 关闭（埋点 `fishing_information_ck`）；
5. 再点一次工具按钮或退出工具 = 关图层并清控制器（不记忆）。
