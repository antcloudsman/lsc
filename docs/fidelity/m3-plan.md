## 0. 本轮口径（先写死，防止按旧假设施工）

1. **抽屉 8 项固定**：地图设置 / 账户设置 / 投诉反馈 / 关于我们 / 联系我们 / 推荐给好友 / 帮助中心 / 用户协议；**「开具发票」取消**，D-016 改记「用户决定取消（不实现）」。
2. **七页「实现形态」一律留空待判**。技术总监 2026-11-07 纠正：不得沿用「协议/帮助页 = WebView 加载本地 assets」的旧假设。服务端 `4b94c26` 已清点 APK：`assets/**/*.html` 共 **35** 个（14 `compassIntroduce` + 21 `webapp`），**不含**用户协议/帮助中心 HTML。形态列由逆向逐页判定后回填（原生页 / WebView 本地 / WebView 远端 / 外部 Intent）。
3. **素材编号**：子页素材依赖项用 **`S-<页名>`**（总监 2026-11-07 定，如 `S-账户设置`），`kind=page-icon / page-html / page-image`，`checksheet=S-<页名>`，与 `assets-deps.json` 对齐。
4. **素材只从 APK 导出**，带 sha256 + APK 路径；禁手绘、近似替代、臆造文案；拿不到 → 标「待素材」并挂起该页。
5. **判据数值必须带「原版文件 + 坐标/节点」出处**（总监 2026-11-07 立规）。本文件凡标「推导」的，都写出可复算的算式，不是观测值。
6. **A-09 动效口径待逆向补录结果**：原版现可直接拉起子页绕过引导页，总监要求补录三类动效；录成后 M2「动效按未验证记账」的口径撤销。本文件先标「待 A-09 结果」，**不改历史结论**。
