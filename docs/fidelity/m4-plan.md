## 3. 本轮业务闭环验收路径（注册 → 登录 → 收藏 → 拉回 → 反馈 → 登出）

> 每一步都要「客户端截图 + dump + 服务端日志/DB 抽样」三件；实现方不自签，由 LC审核验 执行。

| 步 | 动作 | 预期结果（可量化） | 证据 |
|---|---|---|---|
| **1** | 打开账户设置 → 注册页 → 填账号+密码 → 提交 | 201；DB `users` 1 行、`password_hash` 为 scrypt 串（含盐，非明文）；UI 进已登录态 | 截图 + dump（页面标题/字段逐字）+ 服务端 access log |
| **2** | 登出 → 重新登录（先用错密码再正确） | 错密码 401 且提示不泄露账号是否存在；正确 200 + token；token 存入客户端私有存储（不落明文日志） | 截图（两次提示）+ logcat 脱敏样例 + 服务端限流日志 |
| **3** | 收藏点保存（登录态） | 201；DB `favorites` 1 行、坐标与坐向逐字；本地列表即时可见 | 截图 + dump（收藏项文案）+ DB 抽样 |
| **4** | **杀掉客户端 → 重装/清数据 → 登录 → 收藏列表** | 列表拉回同一集合（名称/坐标/坐向逐字一致，条数一致）；断网时显示本地缓存 + 待同步标记（不丢数据） | 重装前后两张截图 + dump + `GET /v2/favorites` 响应 |
| **5** | 投诉反馈提交 | 201；服务端记录（脱敏）；失败态给可区分提示、不伪造成功；空提交走本地必填校验（文案只用已取证静态文本） | 截图（成功/失败两态）+ 服务端日志 + DB 抽样 |
| **6** | 登出 | 旧 token 立即 401；UI 回未登录态；D-022 标注消失；收藏转为本地只读（不删数据） | 截图 + dump + 服务端 401 日志 |

**闭环通过条件**：6 步全部通过且 **误判 0**；其中第 4 步（跨安装拉回）与第 6 步（登出后 token 失效）是**必须由审核验独立执行**的两步，不得由实现方自证。

## 4. 安全红线 → 验收检查项（与 §2.3 M4-08 对应）

| # | 红线 | 验收检查（可复现） |
|---|---|---|
| 1 | 密码哈希 | DB 抽样 `users.password_hash` 前缀为 scrypt 标识；`grep -ri "password" backend/src` 无明文比较；禁 `md5/sha1/base64` |
| 2 | token 不可猜 | token ≥32 字节随机/签名 JWT；连续两次登录 token 不同；DB 只存哈希或签名密钥不入库 |
| 3 | 密钥不入库 | `git grep -i "secret\|password\|key" backend/` 不命中真实值；用 `env`/secrets 文件，compose 用 `${VAR}` |
| 4 | 只绑回环 | `docker compose config` 端口为 `127.0.0.1:8787:8787`；`ss -ltnp` 不出现 `0.0.0.0:8787` |
| 5 | CORS 收窄 | 只允许 App 自身 origin/`null`（WebView 本地页）；`Access-Control-Allow-Origin: *` 必须消失 |
| 6 | 登录限流 | 同 IP 连续失败 5 次 → 429；冷却窗口与重置条件写进契约 |
| 7 | 日志脱敏 | access log 不含密码/token 原文；客户端 logcat 不含 token；日志走 LogRedact |

## 5. 依赖与风险

1. **契约冻结依赖逆向取证**（Stage 1 由 LC逆向 完成）：原版登录/注册字段、错误码、token 头名、收藏同步与反馈接口未取证前，**v2 契约不得冻结**；自建后端以「功能等价」为目标，不照抄原厂接口路径。
2. **不调原厂接口**：投诉反馈/收藏同步一律走自建后端；原版接口只作逆向参考，不发起真实请求（M2 已定：不拿人家服务做试探）。
3. **设备串行**：Stage 2 起每步真机验，单台设备、前置动画 0/唤醒解锁/`rm -f /sdcard/a.xml`/`push + pm install -r -t`。
4. **token 存储**：客户端私有目录/Keystore；**不得**写日志、不得进 dump 的 `text` 节点（验收时 dump 抽查）。
5. **D-022 关闭前提**：登录与提交真实可用、页面标注撤除、审核验独立复验；否则 D-022 保留。
