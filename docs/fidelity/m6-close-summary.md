## 1.1 「重载重放」根因的修法经过一次纠偏（**这条必须写清谁提的、为什么改、最后用什么**）

| 环节 | 内容 |
|---|---|
| **问题** | `P1-1`／`M-01`／`M-02` 同一根因：`onPageFinished` 重放块只补了 `setRoadNet`／`setMode('3d')`，其余控件状态只在点击时下发；且 JS 侧 `toggleNeedle`／`toggleSitNorth`／`toggleGround` **只有 toggle、没有幂等 set** |
| **第一版方案（总监 2026-11-08 提出）** | 「**重放前先用 `getState()` 回读覆盖全部 Java 镜像**」，并定原则「页面状态是权威，Java 镜像只是缓存」 |
| **为什么改（客户端实测反驳，总监当场认错更正）** | `map.html` 里 `localStorage`／`sessionStorage` **命中 0**，页面**无任何持久化**；重载后一律回默认值（`base="ter"` L151、`needleOn=true` L193、`sitMode=0` L197、`contourOn=false` L199、`groundMode=false` L200）。**若在重放前回读，读到的是新页面默认值**，等于把「实景→地形／等高线→关／坐南朝北→0」写回镜像，刚验过的四条「重载后保持」会当场全红 |
| **最终方案（`af8950d`）** | **事件驱动回读 + 重放**：回读点**集中一处**——`onToolClick()` 末尾（`:1749`），页面改状态的那一刻同步校准镜像；重放仍在 `onPageFinished`，顺序 `setRoadNet → setBase → setRidge → setContour → setGround → setSitNorth → setNeedle → setMode('3d')` |
| **回读覆盖** | **7 个字段**：`mode`（→`is3D`）、`sitMode`（→`sitMode` + `southNorthOn = sitMode!=0`）、`needle`（→`pointerOn`）、`contour`、`ground`、`ridge`、`base` |
| **为什么放一处** | 散在各 `case` 里靠人记，下一个人加控件就漏；集中在 `onToolClick()` 末尾则**新控件自动被覆盖** |
| **原则（终稿，写进注释）** | **页面状态在它有效的时候是权威（改状态瞬间回读）；重载那一小段时间页面已重置，以最近一次回读的镜像为准。镜像只能被「事件驱动的回读」刷新，不能由单向写入撒谎。** |
| **被否决的方案** | `map.html` 加 `localStorage` —— 总监**不批**：会变成第三份持久状态（页面 localStorage + Java 镜像 + JS 变量），且 WebView 存储随时可被清，语义不如内存镜像 |
| **numstat** | `57 0 MainActivity.java`；`bare LF 203→203`；CR `4117→4174`（+57，即插入行数），**无空白重排** |
