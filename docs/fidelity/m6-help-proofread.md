## 3 新增门禁：生成物溯源（技术总监 2026-11-08 指定）

MD 是唯一源、HTML 是生成物，所以 lint 加一条：**HTML 头部 `GENERATED from <src> @ <blob sha>` 必须与源文件当前 blob sha 一致**，不一致即 FAIL。

```bash
python tools/fidelity/evidence-lint.py \
  --root app/android/app/src/main/assets/lc-help \
  --generated-html app/android/app/src/main/assets/lc-help/index.html \
  --source docs/product/help-center.md
```

三例实测（工具已实现 `check_generated`）：

| 用例 | 结果 |
|---|---|
| 现手写稿（无 `GENERATED` 头） | **FAIL** `missing header … (hand-written or generator not wired)`，exit 1 |
| 头部 sha = 源 blob（`2c3b8e95…`） | **PASS**，exit 0 |
| 头部 sha 伪造（`deadbeef…`） | **FAIL** `stale/mismatched: header deadbeef… != source blob 2c3b8e95…`，exit 1 |

> 说明：**现在这条是预期 FAIL**——生成脚本还没接（总监已定「手写稿先保留」）。生成链路落地后此门自动转绿；在那之前谁手改 HTML 都会被这条拦住。
