2. **可以写**：「门户《服务条款》（5 条）与《版权声明》（4 段）正文已于 2026-11-09 取得（URL + 200 + 摘录见 §3），

## 5. 复现命令

```powershell
$env:HTTP_PROXY='';$env:HTTPS_PROXY='';$env:ALL_PROXY=''
[System.Net.WebRequest]::DefaultWebProxy=$null
# 1) 空壳确认
(Invoke-WebRequest 'https://www.tianditu.gov.cn/about/service' -UseBasicParsing).Content   # 982 B，只有 <div id="root">
# 2) 正文来源
$r=Invoke-WebRequest 'https://www.tianditu.gov.cn/about/static/js/main.a15946b3.js' -UseBasicParsing
$t=$r.Content -replace '\\u([0-9a-fA-F]{4})',{ param($m) [char][Convert]::ToInt32($m.Groups[1].Value,16) }
foreach($p in @('服务条款','缓存','离线','下载','版权声明')){ "$p = " + ([regex]::Matches($t,$p)).Count }
# → 服务条款 = 11 / 缓存 = 0 / 离线 = 0 / 下载 = 0（"下载"唯一命中是 antd 语言包 downloadFile）/ 版权声明 = 8
# 3) 控制台
Resolve-DnsName console.tianditu.gov.cn        # 不解析
```
