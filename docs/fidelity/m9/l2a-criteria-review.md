## A 组：不补则判据不成立

### A1 分母必须锁「掩膜像素数」
盘面在 1456 画布上直径占 37.5%（`map.html:3004` 注释「盘面只占画布的 37.5%，居中」），盘径 ≈549 → 掩膜 ≈ 23.7 万 px；全画布 1456² = 212 万 px，**差 8.96 倍**。
若分母写成全画布，2% = 42,399 px ≈ 盘面面积的 18%，判据失去判别力。
⇒ 判据须写「分母 = 掩膜像素数」，报告同时给**比例与绝对像素数**两列。

### A2 掩膜只能由 canvas 的 alpha 通道生成
`drawCompass()` 每帧先 `ctx.clearRect(0, 0, size, size)`（`map.html:2807`），canvas 盘外真透明，`alpha>250` 可用；而原生 screencap **整图不透明**，若用它算 `alpha>250`，掩膜退化为全屏，A1 的分母随之失效。
⇒ 判据须写「掩膜由 canvas 侧生成，同一掩膜套两张图」。

### A3 环存在性必须双向
现判据只判「native 有、canvas 无（连续段 ≥3°）」。A 轮（M9-A）的教训是**多画与少画都会发生**（顶部红三角即多画）。
⇒ 须改为 `native-only ≥3°` 与 `canvas-only ≥3°` 双向，任一成立即 FAIL，报告中分别列段。

### A4 时序锚点用 `groundRenderSeq`，`sig` 只能当类型锚
`sig` 只随 `dialType` 变，同类型下的重绘（透明度重算、纹理重建、脏标记复位）**不改 sig**，守卫会放行旧图。
⇒ 取图前后 `groundRenderSeq` 必须相等且 `texDirty===false`；`sig` 保留作「类型一致」校验。地图侧已确认新增 `groundRenderSeq`（每次贴地画布重绘成功自增）。

## B 组：建议同时补（不补我仍可签，但报告要说明为什么没补）

### B1 阈值用「同实现基线」定，不直接写 2%
测试实测：1456 空间 + σ=1.5 的**地板差异 = 3.33%**，固定 2% 会把正确实现判 FAIL。
⇒ 判据改为 `占比 ≤ B + 1.0pp`，`B` = 同实现控制组（两侧同路径出图）的实测基线，且 `B` 与最终阈值都写进报告。

### B2 逐环半径数值对照（`Δr ≤ 1.5px`，归一化到 1456）
存在性向量只判「有没有」，半径才判「位置对不对」。两项并列后，结构层才闭环。

## 一条技术判断（供总监裁「原生单帧导出」）

若原生侧走 screencap（1228×2700）裁+缩到 1456，则 3.33% 是**这条通道的地板**（插值进来的），不是盘面真实差；且 screencap 是屏幕合成后的图，会把背景与亮度混进差异。
若改为「原生把 `CompassView` 直接 draw 到 1456 Bitmap」（地图提的 debug 命令，`evaluateJavascript` 回调落盘，不受 logcat 行长限制），则两侧都是 1456 原生出图，**插值这一环消失**，地板应降到只剩抗锯齿/半像素，2% 类阈值才有意义；同时掩膜两侧各自可算、可交叉核对。
⇒ 我方判断：**该加**，理由是判据性（消掉三个混淆源），不是省事。
