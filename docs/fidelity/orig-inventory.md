## 4. 与 LC 现有实现的初步对照信号（只列已实测差异，供 Stage 3 使用）

1. **审图号**：原版底栏常显「数据来自世纪空间 审图号：GS(2026)1219号」；LC 为「底图：天地图地形 · 审图号：未确认」（合规差异，D-008/T-13 已登记）。
2. **搜索坐标解析**：原版要求「经度,纬度」且给出 GCJ02/WGS84/BD09/CGCS2000 四个结果；LC 是否支持四坐标系**未验证**。
3. **VIP 门禁**：原版 11 处功能需会员并 `FLAG_SECURE`；LC 按 D-006 全解除 —— 对标时这些页面只能比「功能内容」，不能比「付费墙」。
4. **罗盘浮层**：原版为 WebView `compass` canvas 925×925 + `pointer` 81×324（DOM 可测），LC 为原生 Canvas —— 半径/指针尺寸可量化对齐，渲染层级需单独比。
5. **地图工具面板**：原版 4×4 十六项 + `编辑`；LC 侧工具集合与分组**需逐项对齐**（含「超清地图/看山脉/看水系/历史影像/地理影像/钓点/轨迹记录」七项）。
