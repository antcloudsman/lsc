## 3. 判定规则（预置，避免事后争论）

1. **通过**：本表观测点全部满足 + 双图同批次 + dump 可复现 + 量化值在阈值内，四者缺一不通过。
2. **不通过**：任一观测点缺失或超阈值；写明「期望 vs 实测」与差值（px/文本/动作）。
3. **无法复现**：命令/坐标已给且按纪律执行仍得不到该状态；记录命令、设备、时间，转「待确认」，不得写成通过。
4. **不许自签**：实现方提交自测只能作参考，判定以本表观测点为准。
5. **判据变更**：只允许在交付前改；交付后若发现判据本身错，按 §0 方式登记并同时给「按旧判据/按新判据」两种结论，由总监裁。
