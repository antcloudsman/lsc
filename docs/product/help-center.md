## 2. 地图基础

### 2.1 手势

- **双指捏合**缩放；单指拖动平移；缩放也可用右列 `+` / `−`。
- **本版没有双击缩放**：`map.html` 无 `dblclick`/`lastTap`/`tapTimer`，Java 侧无 `GestureDetector`/`onDoubleTap`（审核验 2026-11-08 代码与实测双证）。**双击 = 两次单点落点，没有缩放语义**。
- **拖动方向**：手指向右，地图内容向右移动（与原版一致，M6 第 2 条已实测：2a 八条 8/8、2b 三档角误差 0°）。 状态：`已验收`

## 3. 罗盘

### 3.1 打开与关闭

- **左列「罗盘」**或「更多」→「罗盘」；罗盘以浮层形式叠在地图上（**不是独立页**）。 状态：`已验收`
- 关闭：罗盘态右列「地图」回到纯地图态，或点浮层「隐藏」。 状态：`已验收`

### 3.2 读数怎么看

- **向/坐**、**地盘 / 人盘 / 天盘**、**分金**、**72 龙 / 60 龙**、**卦**——同一朝向口径成套显示。 状态：`已验收`
- 智能读盘弹层里，`地盘正针二十四山`、`穿山七十二龙`、`百二十分金`、`透地平分六十龙`、`人盘中针`、`天盘缝针` 六项带「💎 点击查看»」标记；**可直接看到的只有「先天/后天卦位 + 洛书数」**。 状态：`待核对`
- **待核缺陷（2026-11-08 审核验实测）**：本项目**无 VIP 体系**，这六项却仍带 💎 门槛标记。若明细点不开 = 与我方「免费无门槛」原则冲突；若点得开 = 文案误导。两种情况都要处理，**不能按“原版如此”留着**。
- **缩放途径**：双指捏合、右列 `+`/`−`、罗盘工具条「缩放」。**双击没有缩放语义**（两次单点 = 落两个标记）。
