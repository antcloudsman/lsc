1. **状态标记**：每条功能带一个状态——**`已验收`**（有真机验收记录）/ **`待核对`**（代码或入口在、状态未复核）/ **`未实现`**（只在 §13 出现）。**正文只写 `已验收` 与 `待核对`，且 `待核对` 必须显式标出。**

## 2. 地图基础

### 2.1 手势

- **双指捏合**缩放；**单指拖动**平移；**双击**放大一级。
- **拖动方向**：手指向右，地图内容向右移动（与原版一致，M6 第 2 条已实测：2a 八条 8/8、2b 三档角误差 0°）。 状态：`已验收`
- 图：`help-02-drag.png`（拖动中）、`help-04-zoom.png`（缩放后）

### 2.2 底图切换（地图 / 实景）

- 罗盘态右列「**地图**」「**实景**」两枚，互斥；切换会同时更换底图与罗盘态显示。 状态：`已验收`
- 图：`help-05-basemap-vec.png`、`help-06-basemap-img.png`

### 2.3 角注与审图号

- 底部有数据来源与审图号角注。**本项目为自建/免费数据源，审图号状态为「待核对」**——文档里**只写「底部显示数据来源角注」，不写具体审图号**。 状态：`待核对`
- 图：`help-07-attribution.png`

## 3. 罗盘

### 3.1 打开与关闭

- **左列「罗盘」**或「更多」→「罗盘」；罗盘以浮层形式叠在地图上（**不是独立页**）。 状态：`已验收`
- 关闭：罗盘态右列「地图」回到纯地图态，或点浮层「隐藏」。 状态：`已验收`

### 3.2 读数怎么看

- **向/坐**、**地盘 / 人盘 / 天盘**、**分金**、**72 龙 / 60 龙**、**卦**——同一朝向口径成套显示。 状态：`已验收`
- 点盘面可查看对应圈层说明（「点击查看」）。 状态：`待核对`
- 图：`help-08-compass-readings.png`

### 3.3 盘面切换

- 盘面列表四组：**自定义 / 常用 / 简易 / 综合**；**常用 5 项可用**，另两组为占位。 状态：`已验收（常用）`｜`待核对（其余组）`
- 设置里「恢复默认」可把盘面栅格与配色恢复。 状态：`已验收`
- 图：`help-09-dial-list.png`

### 3.4 罗盘工具条（5 项）

**切换 / 旋转 / 缩放 / 透明度 / 天支线**。 状态：`已验收`（天支线：开关状态持久化）
- 图：`help-10-toolbar.png`

### 3.5 罗盘态左列 6 项

**截屏 / 等高线 / 罗盘复位 / 罗盘锁定 / 读盘 / 贴地**

| 项 | 做什么 | 状态 |
|---|---|---|
| 截屏 | 保存当前罗盘与地图画面 | `已验收` |
| 等高线 | 显隐等高线 | `已验收` |
| **罗盘复位** | **把偏转的地图立即回正北**（不是切换显隐），清锁定/跟随、3D 下退 2D，**不动缩放与中心** | `已验收` |
| 罗盘锁定 | 锁定当前盘面朝向 | `已验收` |
| 读盘 | 读出当前盘面信息 | `待核对` |
| 贴地 | **入口存在、名称为「贴地」，但效果未实现**（见 §13） | `未实现` |

- 图：`help-11-compass-left.png`

### 3.6 罗盘态右列 4 项

**地图 / 实景 / 坐南朝北 / 指针开关**

| 项 | 做什么 | 状态 |
|---|---|---|
| 地图 / 实景 | 底图与罗盘态互斥切换 | `已验收` |
| 坐南朝北 | 盘面朝向取向切换 | `已验收` |
| 指针开关 | 纯地图态下指针图隐藏；罗盘态/实景态由开关显示或隐藏 | `已验收` |

- 图：`help-12-compass-right.png`

### 3.7 校准与精度

- 手机罗盘受磁干扰，**建议「8 字晃动」校准**；读数旁显示精度提示。 状态：`待核对`（以实现为准，图与文案须与该页一致）
- 图：`help-13-calibration.png`
