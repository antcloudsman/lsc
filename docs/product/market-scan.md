**读表要点（只讲对自用有用的）**

1. 原版自己的差评全指向「收费/打不开」，没有一条骂功能——说明这套「罗盘 + 三维山水」的功能组合是被需要的，只是商业模式把人赶走了。LC 去商业后，这些功能直接可用。

## 3. 可移植功能点池（按自用价值排序）

> 判据只有一句：**这个东西是否让「日常看山水 / 定坐向」少一步、少一次怀疑、少一次翻手机**。
> 代价 = 粗估人日（含自测）；优先级对应 `PRD-v0.1.md`（内容为 v0.2）的编号。

| 功能点 | 来自 | 自用价值 | 代价 | 结论 |
|---|---|---|---|---|
| 点选海拔 / 坡度 / 坡向 | 堪舆、山水地图 | 看山势时「这里多高、朝哪、陡不陡」一次点出来 | 4–6 | **P0-4** |
| 本地留档（读数+截图一张图） | 无竞品明示（自推） | 看到好山势/定好坐向，一键存下，不用手抄 | 6–8 | **P0-2** |
| 离线 / 弱网降级 | 原版、一起看地图的「打不开」 | 山里没信号也能看罗盘、看刚才那片山 | 4–6 | **P0-3** |
| 校准 + 磁偏角 + 精度/倾斜提示 | 开运、iOS 的读数差评 | 读数不对时知道「为什么不对、怎么校」 | 4–6 | **P0-1** |
| 地名 / 坐标搜索跳转 | 一起看地图 | 想到某座山、某个村，直接跳过去看 | 3–5 | **P1-1** |
| 距离 / 面积量测 + 多点标注 | 一起看地图、原版 | 看地块范围、两点距离 | 4–6 | **P1-2** |
| 地形剖面（两点连线看起伏） | 无竞品明示（自推） | 判断山脊走向、视线遮挡 | 3–5 | **P1-3** |
| 输入度数 → 坐向速查 | iOS 風水羅盤 | 别人报个度数，立刻知道坐向、兼向 | 2–3 | **P1-4** |
| 等高线叠加 | 山水地图 | 看坡度分布、山脊线，比纯晕渲清楚 | 5–8 | **P1-5** |
| 3D 立向标记（射线拾取） | 原版（2D 已有） | 在山上直接标「这里坐 x 向 y」 | 2–3 | **P0-4 附属** |
| 天池 + 天心十道 + 端平 | 开运、iOS | 罗盘看着更像罗盘，顺带提示端平 | 1–2 | 并入 **P0-1** |
| AR 实景罗盘 | 通易 | 举手机对实景叠盘面；自用炫但费电、难对准 | 8–12 | 不做（收益/成本比低） |
| 街景 | 原版（缺失项）、一起看地图 | 看房子周边、进山路口 | 4–6 | P2（依赖第三方街景可用性） |
| 历史影像对比 | 一起看地图 | 看地貌变迁；自用频次低 | 8–12 | 不做 |
| 老黄历 / 择日 | 山水地图 | 自用可选，纯本地展示 | 5–8 | P2（默认关） |
| 盘面主题 / 换肤 | 通易 | 1:1 已有 5 盘面，够用 | 2–4 | 不做 |

**可移植点的取舍说明**

1. **只搬「看地形」和「读方位」两类**：测量、剖面、高程点选直接减少出门次数和返工；换肤、AR、社区类只增加复杂度。
2. 一起看地图的标注/测量是它口碑里少数被认可的部分（简介主打），搬「测量 + 标注」即可，**不搬**它的会员/多端/历史影像体系。
3. 老黄历虽然出现在山水地图简介里，但它是内容型功能，跟「看山水/定坐向」无关，所以只给 P2。

## 4. 个人自用场景下的合规注意点（三条）

> 自用 = 不上架、不对外提供服务、不商业分发。以下不是上架论证，只是「别给自己惹麻烦」的边界。

1. **天地图个人 key 的配额**：省级节点公开口径为个人注册**每服务每天 1 万次**（天地图·福建，2026-10-09）；平台保留对「大规模占用」限流的权利（《地理信息公共服务平台管理办法》第十六条）。当前 `map.html` 把 key 明文内置（`assets/map.html` 顶部 `var KEY`），**APK 一旦外传就等于把 key 送人**。做法：用自己申请的个人 key、3D 与底图双通道算清楚日调用量、瓦片做缓存降级。
2. **风水内容只在本地用**：不发布、不传播含吉凶断语的成品；只把地图截图发给别人或公开时，才涉及「地图来源：天地图」与审图号标注（《地图管理条例》第二十二条、2024 年两部门 App 登载地图通知）。自用自己看，不标注不构成问题。**注意**：原版审图号 `GS(2026)1219号` 属世纪空间（真机 `a407d41`），LC 用天地图，**禁止沿用**（PRD T-13）。
3. **不内置第三方付费/广告 SDK，不上传位置与记录**：一旦对外提供地图服务就从「自用」变成「互联网地图服务」，需要测绘资质（《地图管理条例》第三十三条）。保持纯本地、无账号、无上报，这条风险就不存在。

依据：[地理信息公共服务平台管理办法（第十六条）](http://www.nys.gov.cn/publicity_gtzyj/wjzc25/28041)、[天地图·福建 个人 1 万/日（2026-10-09）](https://zrzyt.fujian.gov.cn/zwgk/xwdt/zrzyyw/202610/t20261009_7222216.htm)、[《地图管理条例》](https://www.gov.cn/zhengce/content/2015-12/14/content_10403.htm)、[2024 年规范 App 登载地图行为](http://www.chinadevelopment.com.cn/news/zj/2024/05/1895150.shtml)

## 5. 给 PRD 的输入（判据，不是结论）

1. **省事度**优先于「功能多」：点一下出海拔 > 多 10 个盘面。
2. **可信度**优先于「好看」：校准、真北口径、垂直夸张倍率必须可见。
3. **不破坏 1:1**：以上任何一条都排在「基线读数/圈层与 mechanics.json 一致」之后；增量一律可开关、默认关。
