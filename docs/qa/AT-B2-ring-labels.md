## 0. 判定原则（执行前先读）

1. **golden 唯一来源**是 `rings[type-1].labels[i]`；`JIAZI[]`、`wangxiang()`、`borrow_branch()`、教材六十甲子序列**一律不得当答案**。
2. **索引与落位**：`i = floor(((h − offset + 360) % 360) / interval)`；文字画在该格**中心** `offset + (i + 0.5) × interval`——不是 `i × interval`，也不是格边界。
3. **逐字节比较**：保留 U+200C 与空格。`甲山 戊子`（有空格）、`甲山甲子`（无空格）、`壬子 庚子`（有空格）三者不可互相替代。
4. **两端同源**：Rust 与 Java 必须用同一张表、同一公式；只改一端即 FAIL。
5. 本文件 §2.3 的 84 格 golden 已按上述公式对 `mechanics.json` **脚本复算**，与 R2.1 逐格一致（2026-11-05，14 环 × 6 方位）。
