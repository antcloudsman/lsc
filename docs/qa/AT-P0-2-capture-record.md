# AT-P0-2 一键留档验收（截图 + 读数卡片 + 本地记录 + 相册/分享）

- 出：LC产品｜执行：LC客户端（自测）+ LC测试（独立复核）｜评审：技术总监
- 基线：`develop` @ `92726d8`
- 依赖已闭环：B-09 截图修复（`afb8acd`，PixelCopy）、T-11（相册/文件名/无 GPS EXIF/无水印）、T-15（14 行读数）、T-13（来源 + 审图号「待核对」）、B8b（顶部向北/坐南 + 坐山/向山）
- 范围：罗盘页截图、地图/3D 截图、卡片合成、记录 CRUD、相册落点、EXIF、系统分享、无定位权限、开关全关
- **不做**：位图盘面（D5/B-04）、3D 点读（P0-4）、水印/角标（明确不加）、宅卦（B8c 未取证）

## 0. 判定原则

1. 读数 golden 只取 `rings[].labels`；记录存的是**保存时快照**，回看不得重算。
2. 相册路径固定 `Pictures/LC/`；文件名 `坐向{坐}向{向}_yyyyMMdd_HHmmss.png`。
3. **EXIF 不得含 GPS**：PIL 的 `get_ifd(0x8825)` 为空，或 `exiftool -GPS:all` 无输出。
4. 分享物必须**与原图同源**（SHA256 相同，或分享预览与原图逐像素一致），且无水印、无角标。
5. 角注必须有「地图来源：天地图 · 审图号待核对」（T-13 未核对期），**不得**出现世纪空间/高德/腾讯的号。
6. 结果只有 PASS / FAIL / BLOCKED；证据缺 = BLOCKED。

## 1. 前置

- [ ] APK 来自 `develop` 构建（不是共享树未提交代码）；冷启动无 FATAL
- [ ] 真机 `L2E0222531014833`（JAD-AL00 / Android 12）

## 2. 用例

### P2-01 罗盘页截图内容

- 步骤：注入 heading 90 → 罗盘 Tab 点「截图」→ 打开分享面板 → `adb pull` 原图。
- 期望：图含「底图 + 罗盘 + 读数面板」；宽 ≥1080 px；`white_ratio < 0.2` 且内容区 `non_dark > 0.5`（客户端旧实测 0.012 / 0.881 可作参照）；无黑边、无空白。
- 判据：全符合 PASS；白图/黑图 FAIL（即 B-09 回归）。

### P2-02 地图 / 3D 截图

- 步骤：地图 Tab → 进 3D → 点「截图」。
- 期望：WebGL 山体正常渲染、非黑屏；HUD（FPS / 海拔 / 倍率 / 贴面）在；图尺寸与屏幕一致。
- 判据：PASS/FAIL；黑屏 FAIL。

### P2-03 相册落点与文件名

- 步骤：截图后 `adb shell ls -l /sdcard/Pictures/LC/`；再查 MediaStore：`adb shell content query --uri content://media/external/images/media --projection _display_name --where "_display_name LIKE '坐向%'"`。
- 期望：新文件存在；名形如 `坐向酉向卯_20261105_041530.png`（坐/向与当前 heading 对）；MediaStore 可见、系统相册可见。
- 判据：路径 / 命名 / 可见 三项全 PASS。

### P2-04 EXIF 洁净

- 命令：
  ```powershell
  python -c "from PIL import Image; im=Image.open('shot-compass.png'); print(dict(im.getexif())); print(dict(im.getexif().get_ifd(0x8825)))"
  ```
  期望：GPS IFD 为 `{}`（或整份 EXIF 为空）；`exiftool -GPS:all shot-compass.png` 无输出。
- 判据：出现任一 GPS 字段 FAIL。

### P2-05 分享形态

- 步骤：截图后拉起系统分享；选「保存到文件」或「发送到本机」任一路径落一份。
- 期望：分享物 SHA256 == 相册原图 SHA256（走文件 URI 时）；或分享预览与原图逐像素一致；无水印、无角标。
- 判据：PASS/FAIL。

### P2-06 来源与审图号角注（T-13）

- 期望：图内角注为「地图来源：天地图 · 审图号待核对」。
- 判据：文案一致 PASS；空白/留空号 FAIL；出现 `GS(2026)1219号`（世纪空间）或高德/腾讯号 FAIL（合规）。

### P2-08 顶部两行（B8b；宅卦不做）

- 期望：第一行「向北 90.0° / 坐南 270.0°」；第二行「坐酉山 向卯山」（`i(90)=5→卯`、`i(270)=17→酉`，TYPE_4）。
- 判据：两行都对 PASS；**出现宅卦（如「离宅」）即 FAIL**（B8c 未取证，不得猜）。

### P2-09 记录 CRUD 与快照一致性

- 步骤：存 3 条（不同 heading）→ `am force-stop` → 重开 → 逐条回看、改名、删除一条、再重启。
- 期望：3 条仍在；回看读数与保存时**逐字一致**（快照，不重算）；改名/删除立即生效且重启后保持。
- 判据：全 PASS。

### P2-10 无定位权限

- 步骤：系统设置撤销定位权限（或首次拒绝）→ 截图 + 存记录。
- 期望：仍可保存；坐标显示「未授权」；不崩溃；文件名/角注正常。
- 判据：PASS/FAIL。

### P2-11 开关全关回退

- 步骤：关闭 P0-2 开关 → 罗盘页。
- 期望：无「存记录」入口；**截图按钮保留**（属 B-09 基线修复，不随 P0-2 关闭）；其他 Tab 不受影响。
- 判据：PASS/FAIL。

### P2-12 失败提示（可选，不判失败）

- 若可模拟存储失败：Toast 必须明确失败原因、不崩溃；无法模拟则记「未模拟」，不算通过也不算失败。
