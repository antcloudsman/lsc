## 4. 结论与口径声明

1. **不能拿本表推算 M4 总投入**：13 项交付里只有 5 项有自报时间戳（41 分钟），其余 8 项未记录。任何「M4 一共花了 X 人日」的结论都缺依据。
2. 计划侧的总盘（`m4-plan` 的 14.0 人日 + 20% 缓冲 ≈ 16.8）是**估工**，与本表实测增量不是一个东西，报告里不得混用。
3. 从下一轮起，交付模板固定要求：`开工=HH:mm / 收工=HH:mm / 墙钟 / 人日 / 返工轮次`，缺一项则该项按「未记录」入账。
