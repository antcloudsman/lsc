# 密钥闸门白名单 tests/secrets/allowlist.txt
#
# 只对「hex 启发式告警」生效；**真实 key 命中不可豁免**（那条是 FAIL，必须删掉并轮换 key）。
# 格式（每行一条，`#` 开头为注释）：
#   <glob> <理由>
#   glob : 相对仓库根的 posix 路径，fnmatch 语义（`*` 会跨目录）
#   理由 : 必填；没有理由的豁免等于关掉告警
#
# 什么该进白名单：确实不是 key 的 32 位十六进制串（第三方 SDK 的固定 id、内容哈希等），
# 且改不动/不该改。原版第三方 key 这类**真泄露**不许进白名单——要删。
# 例：
#   app/android/app/src/main/assets/legacy-embed.html  第三方播放器嵌入 id，非密钥且由上游固定
